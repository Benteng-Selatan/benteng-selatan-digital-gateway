# Checklist Data Resmi Kelurahan

Sebelum serah-terima final, seluruh konten berikut harus diverifikasi oleh pejabat atau petugas yang berwenang.

| Area | Pemeriksaan |
|---|---|
| Identitas | Nama resmi kelurahan, tagline, dan deskripsi |
| Pemerintahan | Nama lurah dan uraian pemerintahan |
| Kontak | Alamat, jam layanan, telepon, email, WhatsApp, media sosial, dan peta |
| Layanan | Nama layanan, persyaratan, tahapan, lokasi, kontak, dan catatan |
| Statistik sosial | Nilai, tahun, sumber, dan persetujuan publikasi |
| UMKM | Nama, deskripsi, gambar, lokasi umum, dan persetujuan kontak |
| Peta | Nama lokasi, kategori, koordinat, deskripsi, dan tautan peta |
| Wisata/budaya | Judul, isi, gambar, lokasi umum, dan sumber informasi |
| Privasi | Tidak ada NIK, KK, alamat rinci warga, atau nomor pribadi tanpa persetujuan |
| Placeholder | Tidak ada teks “belum diisi”, data contoh, atau informasi yang belum diverifikasi |

Jalankan pemeriksaan bantu:

```bash
npm run content:check-official
```

Hasil script tetap harus ditinjau manusia karena validitas substantif tidak dapat dipastikan hanya melalui kode.
